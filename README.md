Globe Internship — Slot Adherence & Operations System

Primary Contribution: Slot Adherence Development, Dashboard, Reporting & Automation

A collaborative internal web application developed during my internship with the Globe Broadband Team.

The system supports operational monitoring, Slot Adherence, ticket and workorder management, ageing information, tools auditing, reporting, and data visualization.

This repository is my fork of the original team project, maintained as part of my professional portfolio to document my contributions and technical experience.
